# Public release scope

Release prepared on 2026-11-19 from the personal ST01 Y700 offline test project.

Included: the Android WebView shell, a generic local-only sample page, build files,
and original project documentation. The Android activity was adapted from the
personal test app to use a standard Gradle build and a clean generic namespace.

Excluded: the hosted website bundle, its JavaScript knowledge and rule data,
translated game text, card scans, artwork, model photographs, maps, rules PDF,
all APKs, signing material, build output, local screenshots, and device evidence.
The public app therefore opens to an empty setup page until its builder adds
content they have the right to distribute.

This is a source release only. No application package or personal device data is
published.
